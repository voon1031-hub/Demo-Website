# Demo-Website

MY FIZZ 气泡水：一个「投币 → 掉罐 → 畅饮」的滚动叙事官网（英文页面），黑色棚拍、未来感 3D 风格。

## 页面结构

1. 投币：滚动时一帧帧播放 AI 视频，硬币投进透明胶囊贩卖机，按下按钮，整台机器亮起
2. 掉落：镜头冲进发光管道，罐子一边往下掉一边在三款口味之间整罐切换（不混色），旁边同步滚出该口味的配料；最后像拉霸机一样随机停在一款，罐子贴上 Your drop
3. 畅饮：播放掉出来那一款的 AI 视频，从取物口拿起、喝下、冰块气泡水花爆开，最后是 Ahhh. 清爽收尾
4. 三款口味详情卡，随机掉出的那款会标上 Your drop
5. Made in Malaysia 品牌区与页脚

每次打开网页，三款出场的顺序和最后掉出的口味都是随机的。顶部的小 LED 屏会跟着剧情变化（Insert coin → Credit 01 → Dropping → Drop · Mango → Enjoy）。

右上角可以开启音效（投币、按钮、机器启动、掉落、开罐、气泡、水花），默认静音。音效全部由浏览器实时合成，没有音频文件。

## 加载速度与流畅度

AI 生成的原始素材太大（首次打开约 80 MB，视频整段只有 1 个关键帧，拖一下滚动条就要从头解码），所以网页用的是压缩版：

- 首次打开约 9 MB（手机约 8 MB）。投币视频最先加载，加载完才依次加载图片和随机选中那一款的视频，互不抢带宽。
- 视频每 8 帧（手机 6 帧）一个关键帧，没有 B 帧，滚动时每次拖动只需解码几帧。电脑用 1280×720，手机用 540×960 的竖屏裁切版。
- 图片是 WebP（背景透明的罐子和水果保留透明）。
- 去掉了会拖慢渲染的东西：全屏颗粒叠加层、颜色渐变过渡、大面积模糊阴影；背景大字轮廓改成常驻图层，切换口味时不用重绘。
- 设备跟不上（低于约 40 帧）时会自动关掉装饰特效（背景大字、气泡粒子、光晕），故事本身不受影响。网址后面加 `?perf=lite` 或 `?perf=full` 可以固定特效等级，方便对比不同设备。

## 文件

- `index.html`：页面本身，HTML、CSS、JS 都在这一个文件里，没有构建步骤
- `design/reference-cans.jpg`：最初的三款罐身设计参考图
- `design/assets.json`：Higgsfield 生成的原始素材（任务编号和文件名）
- `design/media.json`：压缩后素材的线上地址，网页实际加载的就是这些
- `design/optimize-media.sh`：压缩脚本。把原始素材放进一个文件夹后运行 `design/optimize-media.sh <原始素材目录> <输出目录>`（需要 ffmpeg 和 Pillow），就能重新生成全部压缩文件

## 素材

图片和视频是用 Higgsfield 生成的（GPT Image 2.5 出图，Kling 3.0 出视频）。压缩后的文件放在 Higgsfield 的素材库里，网页直接引用它们的地址。想改成跟网页放在一起：把 `design/media.json` 里的文件下载到 `assets/`，再把 `index.html` 里的 `U` 常量改成 `assets/` 路径（文件名对应 `<id>.mp4` / `<id>.webp`）。

## 本地预览

```sh
npx serve .
```

然后打开终端里显示的地址。
