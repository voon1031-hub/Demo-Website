# Demo-Website

MY FIZZ 气泡水：一个「投币 → 掉罐 → 畅饮」的滚动叙事官网（英文页面），黑色棚拍、未来感 3D 风格。

## 页面结构

1. 投币：滚动时一帧帧播放 AI 视频，硬币投进透明胶囊贩卖机，按下按钮，整台机器亮起
2. 掉落：镜头冲进发光管道，罐子一边往下掉一边在三款口味之间整罐切换（不混色），旁边同步滚出该口味的配料；最后像拉霸机一样随机停在一款，罐子贴上 Your drop
3. 畅饮：播放掉出来那一款的 AI 视频，从取物口拿起、喝下、冰块气泡水花爆开，最后是 Ahhh. 清爽收尾
4. 三款口味详情卡，随机掉出的那款会标上 Your drop
5. Made in Malaysia 品牌区与页脚

每次打开网页，三款出场的顺序和最后掉出的口味都是随机的。顶部的小 LED 屏会跟着剧情变化（Insert coin → Credit 01 → Dropping → Drop · Mango → Enjoy）。

右上角可以开启音效（投币、按钮、机器启动、掉落、开罐、气泡、水花），默认静音。音效全部由浏览器实时合成，没有音频文件。

## 文件

- `index.html`：页面本身，HTML、CSS、JS 都在这一个文件里，没有构建步骤
- `design/reference-cans.jpg`：最初的三款罐身设计参考图
- `design/assets.json`：所有 AI 素材（Higgsfield 生成）的任务编号和文件名，方便以后重做或下载

## 素材

图片和视频都是用 Higgsfield 生成的（GPT Image 2.5 出图，Kling 3.0 出视频），目前网页直接引用 Higgsfield 的 CDN 链接。等开发环境可以访问 Higgsfield 之后，会把它们下载到 `assets/`，压缩成 WebP，并把视频重新编码成适合逐帧拖动的格式，让滚动更顺、加载更快。

## 本地预览

```sh
npx serve .
```

然后打开终端里显示的地址。直接双击打开 `index.html` 也可以。
