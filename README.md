# Demo-Website

丝语 SOIE Hair Atelier：一个中英双语、视差滚动的美发沙龙官网示例。

## 页面结构

1. 首屏：大字 Logo，Canvas 绘制的动态发丝背景
2. 理念：品牌宣言随滚动逐字点亮
3. 影片：滚动时从卡片放大到全屏，章节（流 / 剪 / 染 / 型）与播放进度同步
4. 服务与价格：剪、染、烫、护四类价目表
5. 预约与联系：带校验的预约表单（演示用，不会真正发送）和到店信息

右上角可切换中文 / English。

## 文件

- `index.html`：页面本身，HTML、CSS、JS 都在这一个文件里，没有构建步骤
- `assets/soie-film.mp4`：品牌影片，1920×1080，16 秒无缝循环，H.264
- `assets/soie-film.webm`：同一影片的 VP9 版本，给不支持 H.264 的浏览器用
- `assets/soie-film-poster.jpg`：影片封面

## 本地预览

```sh
npx serve .
```

然后打开终端里显示的地址。直接双击打开 `index.html` 也可以。

## 上线前需要替换

店名、地址、电话和价格都是示例内容。预约表单目前只在页面内显示摘要，需要接入预约系统、企业微信或邮件才会真正发送。
